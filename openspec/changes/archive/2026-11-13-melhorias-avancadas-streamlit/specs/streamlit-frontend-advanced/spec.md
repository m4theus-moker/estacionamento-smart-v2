# Specification: Streamlit Frontend Advanced Enhancements

## Requirement: Interactive Plotly Visualizations
The Executive Dashboard SHALL use Plotly (`plotly.express`) for rendering interactive charts (revenue trends, peak hours, occupancy distribution, category breakdown) instead of basic Streamlit charts.

## Requirement: Dynamic Theme Toggle
The application sidebar SHALL provide a theme toggle widget allowing users to switch between dark and light themes dynamically.

## Requirement: Notification Webhooks & Triggers
The reservation flow SHALL trigger optional webhook/email notification payloads upon successful booking or cancellation.

## Requirement: Playwright E2E Test Suite
The project SHALL include automated End-to-End tests using Playwright validating core user journeys and administrative pages.
